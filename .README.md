# Consome+

Consome+ — aplicativo Flutter (Android + iOS) para incentivar compras conscientes. MVP com Provider, Hive, temas, testes e CI.

Funcionalidades principais:
- Welcome: captura do nome do usuário.
- Perfil persistido (id, nome, xp, nível).
- Dashboard com barra de progresso XP, dicas, botão +100 XP.
- Reset de usuário.
- Tema claro/escuro.
- Persistência local com Hive.
- Testes unitários e de widget.
- CI: GitHub Actions.

Requisitos
- Flutter (última versão estável)
- Dart SDK compatível

Instalação e execução
1. Clone o repositório
2. Instale dependências:
   flutter pub get
3. Execute em dispositivo/emulador:
   flutter run -d <device>

Build Android
- Debug:
  flutter build apk
- Release:
  flutter build apk --release

Build iOS (requer macOS + Xcode + conta Apple Developer)
- flutter build ios --no-codesign
- Fazer codesign com certificados apropriados antes de enviar.

Persistência
- Hive armazena o objeto Usuario na box 'userBox'.
- SharedPreferences pode guardar preferências (tema etc).

Testes
- Unit tests e widget tests:
  flutter test

CI
- Workflow em `.github/workflows/flutter-ci.yml` roda analyze, test e build apk no push para main.

Notas de desenvolvimento
- Para gerar o adapter via build_runner (opcional):
  flutter pub run build_runner build

- Para publicar no Google Play:
  - Crie keystore, configure android/key.properties e as entradas em build.gradle.
  - Gere AAB e envie via Play Console.
